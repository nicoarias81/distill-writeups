OpenCode: el agente de IA gratuito para ciberseguridad, sin suscripción ni API key

Fuente: «No Subscription. No API Key. ... OpenCode + Cybersecurity» · ver el video original

Resumen

Si se busca una alternativa gratuita a la hora de montar un agente de IA para ciberseguridad, OpenCode es una opción seria: sin suscripción ni API key, con modelos potentes que no cuestan nada de dinero. Se descarga con un solo comando y funciona en dos modos: una interfaz de línea de comandos para terminal, y una interfaz web con una GUI bastante bonita para gente que no quiere depender tanto del terminal. La instalación es simple: el paquete viene como ejecutable —un solo binario, se copia al PATH— y con el subcomando serve la interfaz web queda disponible en una IP local con puerto y contraseña autogenerados.

Modelos gratuitos incluidos

Por defecto, OpenCode ya trae varios modelos gratuitos. Destacan dos: SpaceBunnyAlpha y Nematron 3 Ultra, ambos potentes y sin costo. SpaceBunnyAlpha es el más usado de la semana y es gratuito, con el agravante de que no es un "mini": es un modelo potente, con acceso a herramientas y a funciones de razonamiento. Cambiar de modelo es un slash command (/model) que muestra la lista disponible, con los gratuitos bien visibles arriba.

Skills: el mecanismo que lo convierte en especialista

El quid está en los skills: se le puede pedir a OpenCode que instale un skill —una carpeta con un archivo markdown de instrucciones que guía al agente— directamente desde un enlace de GitHub. La demo muestra dos:

  • UI UX Pro Max: un skill para diseño de interfaces y experiencia de usuario, que convierte al agente en un asistente de diseño con criterio.
  • Anthropic Cybersecurity skill: la joya. Un skill enorme de ciberseguridad ofensiva y defensiva que cubre red team y blue team, forense digital, threat hunting, footprinting y más. La instalación toma unos cinco minutos: se pide a OpenCode instalar el skill desde la URL de GitHub y él clona, configura y queda listo.

Las demos

Con el skill de UI/UX, el agente genera una página web oscura estilo cyber-funk, con lluvia de código tipo Matrix y fuentes glitch, cada vez más pulida conforme se le piden iteraciones. Con el skill de ciberseguridad, OpenCode resuelve un laboratorio de PortSwigger: lee la descripción del lab, la analiza, identifica la vulnerabilidad y la explota, mostrando en pantalla cómo razona el agente paso a paso.

La advertencia ética se repite al final: esto es solo para sistemas propios o con autorización explícita —no con objetivos ajenos—.

Conclusiones

  • OpenCode demuestra que no hace falta pagar suscripción ni API key para tener un agente de IA útil en ciberseguridad.
  • Los skills —instrucciones en markdown instalables desde GitHub— son el mecanismo que transforma un agente genérico en un especialista ofensivo o defensivo.
  • Entre modelos gratuitos potentes, CLI y GUI web, el costo de entrada para practicar hacking asistido por IA es prácticamente cero.
