Minino: una placa de bolsillo para jugar con las redes del día a día

Fuente: «Minino 101 - Ruben Ricapa - Ekoparty 2024» · ver el video original

Resumen

Minino es una placa de hardware hacking de código abierto, pequeña como para llevarla en el bolsillo, basada en el microcontrolador ESP32-C6. El recorrido de la introducción cubre lo esencial: qué tiene la placa, qué se puede hacer con ella de fábrica, cómo actualizar el firmware desde la web y cómo compilarlo desde cero para modificarlo —traducir el menú, crear módulos propios, cambiar el logo—.

La premisa que sostiene todo: al ser open hardware y open source, no hay que conformarse con el binario de los releases. El código fuente está disponible y, con las herramientas de compilación correctas, la imaginación es el límite.

La placa, componente por componente

En el frente: un buzzer para los sonidos, comunicación por I2C y UART, cuatro botones de navegación, una pantalla OLED para el menú y LEDs de estado. En el dorso: dos botones fundamentales —reset y boot, que se usan cada vez que se carga firmware—, un slot de micro SD que guarda backups y la información recolectada, un switch de encendido, portapilas —porque no necesita estar conectada a nada—, USB tipo C para energía y carga de firmware, y un chip GPS para ubicación y fecha.

El cerebro es el ESP32-C6, que define las bandas y protocolos donde opera: Wi-Fi, Bluetooth y una cantidad de protocolos IoT —el datasheet detalla todos los periféricos—. Se dice que cubre 6 tecnologías justamente por esa base.

Qué hace de fábrica

Las funciones básicas:

  • Captura de paquetes Wi-Fi: se elige el canal y la placa almacena SSID, canal y más metadatos de las redes que escucha.
  • Bluetooth spam: emula dispositivos Bluetooth y envía notificaciones para inundar el celular cercano —el ataque de moda en las ediciones recientes del evento—.
  • GPS: fecha y ubicación actuales del dispositivo.
  • War driving: GPS + captura Wi-Fi = recolección de redes mientras uno se mueve. Todo se guarda en la micro SD y luego es compatible con WiGLE, donde se analizan cuántos access points están expuestos y qué protocolos usan.

Para acceder a lo recolectado hay dos caminos: sacar la micro SD y conectarla con un adaptador, o usar el file manager integrado —la placa emula un access point con un servicio web en el puerto 80, uno se conecta y navega toda la información desde el navegador.

Como alternativas open source en el mismo rubro: Pwnagotchi y Wardriver 3000.

Actualizar el firmware: el camino fácil

La vía rápida es la web, con esptool desde el navegador: entrar en modo bootloader —botón boot, el logo congelado lo confirma—, descargar los binarios del repositorio, configurar conexiones y baudrate —clave: un baudrate mal seteado hace que la data escrita no corra—, elegir la dirección de memoria de cada binario, programar y listo.

Compilar desde cero: el camino que habilita todo

Para modificar Minino hay que compilarlo uno mismo. Prerrequisitos: la placa, las librerías make y precommit, y —detalle que ahorra un día entero de frustración— la versión 5.3.1 del SDK de ESP-IDF, no la última, que ya no es compatible con el proyecto. Hay un issue abierto al respecto: compilar con la versión incorrecta termina en errores oscuros y horas perdidas.

Con make el flujo es make attack, make compile, make flash —o un make all— y el firmware custom ya está en la placa.

Tres modificaciones de ejemplo

Traducir el menú. El archivo menu.h contiene todos los nombres que se muestran en pantalla; se cambian las cadenas —"File Manager" por "Administrar archivos", o cualquier idioma— y se recompila.

Crear un módulo. Dos archivos: un HelloWorld.h que se importa en el menú y un HelloWorld.c con la funcionalidad. En menu.h se declara el módulo —nombre, variable, menú padre, acciones al entrar y salir—. En el ejemplo el módulo solo muestra un mensaje en la OLED, pero el módulo puede usar todos los componentes de la placa.

Cambiar el logo. El logo inicial que rebota como un protector de pantalla se puede reemplazar por cualquier imagen: se convierte a bitmap —un array hexadecimal—, se define en el archivo de bitmaps generales, se setea el tamaño, se agrega a la lista y se flashea. El ejemplo usa el logo de DVD, a la espera de que toque las cuatro esquinas.

Lecciones

  • El hardware open source invita a otra relación con la herramienta: no descargar releases, sino entender y modificar el código.
  • Versiones de SDK: usar las que el proyecto documenta, no las más nuevas. Leer los issues evita perder días.
  • Captura Wi-Fi + GPS + almacenamiento local forman un kit de war driving completo y compatible con WiGLE.
  • El modo de acceso remoto —access point emulado con servicio web— hace que ni siquiera haga falta sacar la micro SD.
  • Modificar menús, módulos y logos es la puerta de entrada a contribuciones más profundas al firmware.
