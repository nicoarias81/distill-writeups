WAF resiliente: el firewall de aplicaciones que aprende de cada ataque

  • Video: uz7j8NWA3jk · URL: https://youtu.be/uz7j8NWA3jk · Conferencia: 02_ekoparty · Título original: (WAF) Enhanced with AI through Autonomous Dynamic Learning & Generative Models (Purple AI)-D. Dieser

Resumen

El WAF tradicional está basado en reglas estáticas, se limita a amenazas conocidas y sus actualizaciones suelen ser manuales: cada firma nueva de ataque depende de que alguien la escriba. La evolución con inteligencia artificial aporta aprendizaje dinámico, detección de amenazas nuevas y actualizaciones automáticas. Pero el concepto que se propone ir más allá es el WAF resiliente: un sistema adaptativo que, cuando su modelo de base tiene dudas, consulta a un LLM, incorpora el resultado a una memoria intermedia y se reentrena en bucle —hasta que las cargas útiles que lo bypaseaban hoy son detectadas mañana sin intervención humana.

La demo, en estado de prueba de concepto, muestra el ciclo completo: monitoreo continuo del tráfico entrante, clasificación de cada línea de registro, consulta al LLM en los casos dudosos, actualización de memoria y reentrenamiento —más una segunda fase donde otro modelo de IA genera ataques nuevos para someter a prueba al defensivo—.

Arquitectura del concepto

flowchart LR
    A[Tráfico web entrante] --> B[Modelo de base
Naive Bayes - scikit-learn]
    B -->|sin duda| M[Memoria intermedia]
    B -->|duda en la clasificación| L[LLM
OpenAI / cualquier proveedor]
    L -->|clasifica o crea clase nueva| M
    M -->|reentrenamiento continuo| B
    B --> N[Detección que mejora con el tiempo]
  • Modelo de base: un clasificador Naive Bayes de scikit-learn, entrenado previamente con ejemplos de cross-site scripting, SQL injection y remote code execution. Para vectorizar el texto de cada línea de log se usa TF-IDF Vectorizer —el machine learning trabaja todo en números—, y la clase Multinomial aprende a reconocer los patrones y asignar cada registro a su etiqueta.
  • El LLM como clasificador de respaldo: ante cualquier duda del modelo de base, el registro se envía al LLM, que analiza la línea y devuelve una clasificación (o "no es un ataque"). La ventaja frente a un modelo convencional de TensorFlow: no hay que jugar con niveles de predicción entre 0,1 y 1 —el LLM directamente dice qué es y en qué clase encajar—. Y si la categoría no existe, puede crearla: capacidad que ningún modelo convencional tiene, porque ahí siempre hay que definir todas las etiquetas por adelantado.
  • Bucle de retroalimentación: cada clasificación del LLM alimenta el reentrenamiento del modelo de base. La memoria actualizada va acumulando: "esto no lo conocía, lo consulté, es cross-site scripting, lo memorizo". La próxima vez que aparezca la misma carga útil, ya no consulta: el sistema gana autonomía progresivamente.

Los números y las limitaciones honestas

  • Naive Bayes es un algoritmo deliberadamente básico, suficiente para la prueba de concepto y para casos simples supervisados por el LLM. En producción, con volumen real de logs, corresponde un modelo profundo (TensorFlow, aprendizaje profundo): con muchos datos, lo básico no rinde.
  • El hardware es el desafío silencioso: hay organizaciones sin GPU donde el análisis casi en tiempo real exige ingeniería adicional. Con GPU disponible, implementar un sistema de defensa automatizado e inteligente ya no es problema técnico.
  • La latencia se resuelve con cómputo: la clasificación, la consulta al LLM y el reentrenamiento suceden al mismo tiempo que pasa el tráfico; cuanto más poder de cómputo, mejor funciona en tiempo real.

La fase ofensiva: IA contra IA

La segunda fase de la demo somete al sistema de defensa a un adversario: otro modelo de IA genera cargas útiles nuevas de manera continua para intentar el bypass, con la alternativa de llamar a red teamers profesionales para someter el sistema a prueba. El resultado observado: tras la lluvia de ataques, el modelo de base ya clasifica por sí solo, incluso con variaciones de las cargas útiles que no había visto; solo cuando aparece algo genuinamente desconocido vuelve a recurrir al LLM, actualiza y se reentrena. Sobre esa base se pueden agregar bloqueos y las políticas que cada organización decida.

Preguntas incómodas y sus respuestas

  • ¿Cómo se evita que la moralidad del LLM interfiera? Los proveedores son conscientes de la evolución y un modelo de defensa tiene vía libre: si el uso declarado es defender, el LLM entrega lo que se necesita. La regularización de la IA, como pasó con los drones, seguirá el ciclo clásico: primero asusta y se quiere contener, después se acepta y se convive con ella.
  • ¿Qué pasa con el envenenamiento por falsos positivos? En las pruebas, las versiones recientes de ChatGPT mostraron una precisión altísima para detectar cargas útiles. No se descarta el riesgo, pero la respuesta es la de siempre: siempre tiene que haber un humano mirando que las cosas vayan bien.
  • ¿Hay opción local para reducir latencia? Las versiones comerciales más nuevas no se pueden descargar, pero hay muchísimos modelos open source muy capaces para correr en local.

El pronóstico: ataques zero-day generados por LLM

La advertencia final es concreta: en los próximos meses se verán muchos ataques zero-day creados por modelos LLM, y será traumático para las compañías. Los sistemas como el WAF resiliente son una de las defensas posibles: modelos que aprenden de lo que están recibiendo y toman acción. La historia de la seguridad siempre fue la misma —primero el virus, después la vacuna—, y siempre se va a ir detrás del ataque; pero llegar a tiempo detectando es muy distinto a estar semanas enteras haciendo forense, mirando logs, analizando lo que ya pasó cuando lo podía haber evitado.

Conclusiones

  • El WAF resiliente combina un modelo de base económico (Naive Bayes) con un LLM como clasificador de respaldo: el primero detecta lo conocido, el segundo resuelve las dudas y hasta inventa categorías nuevas.
  • La memoria intermedia y el reentrenamiento continuo hacen que el sistema gane autonomía: cada carga útil que pasa por el LLM queda aprendida y no vuelve a consultarse.
  • Frente a un modelo convencional, el LLM elimina el manejo de umbrales de predicción: responde con una clasificación directa o crea una clase nueva.
  • La prueba adversaria con otro modelo de IA generando ataques continuos demuestra que el sistema aprende incluso las variaciones de las cargas útiles, no solo los ejemplos exactos.
  • El desafío operativo está en el hardware (GPU para tiempo real) y en la supervisión humana permanente contra el envenenamiento por falsos positivos.
  • La carrera ya empezó: los ataques zero-day generados por LLM están a la vuelta de la esquina, y las defensas que aprenden en tiempo real son la diferencia entre mitigar a tiempo y pasar semanas de forense.
